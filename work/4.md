### Key decisions

- **Bukhari Script en .ttf plutôt que .woff2** : le PO a fourni le `.ttf` depuis `~/Downloads/BukhariScript.ttf`. Référencé en `format('truetype')` dans `@font-face`. Conversion en `.woff2` (~50% plus petit) reste un TODO perf, hors scope #4.
- **`client:idle` conservé** comme demandé par le ticket. Pour rendre les tests Playwright fiables (mobile-safari notamment, où l'idle window arrive après le click), j'ai ajouté un marqueur `data-hydrated="true"` posé par le `useEffect` du composant. Le test fait `page.waitForSelector('button[role="switch"][data-hydrated="true"]')` avant toute interaction. Pas de changement du contrat d'hydratation, juste un hook de synchro pour les tests.
- **Pill = `Pill.astro` (statique) pour #4** : le ticket dit « LangToggle Pill (visuel posé, swap wiré dans #5) ». #4 livre donc une primitive Astro qui prend `options: readonly [string, string]`, `current`, `label`. En #5, LangToggle deviendra une .tsx interactive (ou wrappera Pill), mais l'API visuelle est posée.
- **PanelRight (Lucide) pour le bouton toggle Inspect** : icône standard pour « panel à droite ». Le bouton n'apparaît qu'en tablet via `@media (max-width: 1023px) and (min-width: 768px)`, conforme au pattern d'#3.
- **Header rendu via fallback du slot `header` dans DocLayout** : `<slot name="header"><Header /></slot>`. Toute page peut surcharger en posant son propre `<header slot="header">`, mais par défaut c'est le Header système. Évite de devoir ajouter `<Header slot="header" />` dans chaque page.
- **Sliding underline du wordmark = pseudo `::after` qui grandit de 0 → 100%** sur hover. Le dot accent reste visible en permanence (span séparé). Lecture sémantique propre, animation pure CSS, garde `prefers-reduced-motion`.
- **Suppression de `--pass-with-no-tests` sur `pnpm test`** : la suite contient désormais 2 specs réelles. Le flag est conservé sur `pnpm test:a11y` puisque le dossier `tests/a11y/` est encore vide (cible du ticket #11).

### Difficulties

1. **Hydration race en mobile-safari** : `client:idle` + viewport iPhone 14 + click direct → le handler n'était pas attaché. Résolu via le marqueur `data-hydrated` (cf. décision ci-dessus). Sans ça les tests étaient flaky.
2. **Préview server stale sur le port 4321** : un `astro dev` traînait depuis une session précédente. `playwright.config.ts` a `reuseExistingServer: !process.env.CI`, donc Playwright se branchait sur le serveur stale. Run avec `CI=1 pnpm test` ou kill du process. C'est un piège pour la suite — à documenter dans la doc tests ou à reconfigurer (`reuseExistingServer: false`).
3. **Rebuild obligatoire avant `pnpm test`** : `pnpm preview` sert `dist/` sans rebuilder. Workflow attendu : `pnpm build && pnpm test`. Sinon les tests tournent contre une vieille version. C'est le comportement Astro standard, juste à connaître.

### 🟡 Important — knob translateX dégénéré
```css
.theme-toggle[data-theme-state='dark'] .theme-toggle-knob {
  transform: translateX(0);  /* Slide right when in dark mode */
}
.theme-toggle[data-theme-state='light'] .theme-toggle-knob {
  transform: translateX(0);
}
```
Les deux transforms valent `translateX(0)` — le commentaire dit « slide right » mais le knob ne bouge pas entre les états. Soit :
- Implémenter le vrai slide (e.g., `translateX(100%)` en dark, `translateX(0)` en light, avec une track-bar plus large).
- Soit retirer les deux règles redondantes (le toggle reste lisible via le swap de couleur sun/moon).

Non bloquant pour ce ticket — le toggle est fonctionnellement OK, l'état est lisible via les icônes. À traiter au moment du polish visuel (probablement Phase 2 micro-interactions, ticket #16).
