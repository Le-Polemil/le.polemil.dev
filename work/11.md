### Key decisions

1. **Persona specs target user-narrated flows, not unit assertions.** The
   recruiter spec, for instance, intentionally checks elapsed wall time
   (< 5s) rather than a specific selector — it's a "first impression"
   smoke. Detailed selectors for the same content live in the
   component-level specs (`experience-page.spec.ts`, `inspect-panel.spec.ts`)
   and are deliberately not duplicated here.
2. **Skip Calendly + ContactForm via `test.skip`** rather than commenting
   them out. The spec scaffolding stays compiled (catches drift) and the
   day #13 ships, only the `test.skip` → `test` flip is needed. The skips
   are visible in CI output as a reminder.
3. **Axe tag set: `wcag2a / wcag2aa / wcag21a / wcag21aa / best-practice`.**
   Deliberately *not* `experimental` — those rules evolve fast and would
   make CI flaky. WCAG AA is the AC target.
4. **Bumped `--fg-tertiary` (light) instead of suppressing the axe rule.**
   The AC mandates 0 violation, and the failure was real (the muted body
   text on the home page header). Token-level fix is the right blast radius
   — the same token is used on many surfaces. Dark theme value left alone
   (axe didn't flag it ; light bg is the bigger contrast risk).
5. **Lighthouse stays on `warn` (not `error`).** The existing config from
   #22 was `warn`-level; the AC just says "≥ 95 sur 4 catégories" without
   specifying CI gate semantics. Local run on both URLs hit the thresholds
   ; flipping to `error` is a follow-up if scores drift.

### Décisions saines
- **Fix `--fg-tertiary` au niveau token (vs filtre axe).** Le bon blast radius : la couleur est mutualisée sur ≥ 10 surfaces, fixer la cause est juste. Le nouveau `#6a604f` reste cohérent avec la palette warm (proche de `--fg-secondary` #52493a, gap luminance ~ 0.06, suffisant pour la hiérarchie).
- **`test.skip()` pour Calendly + ContactForm** plutôt que tout commenter — le squelette reste compilé, détecte la dérive d'API, et le jour où #13 atterrit on flippe juste `skip` → ouvert.
- **Tag set axe sans `experimental`** — bon réflexe pour un gate CI stable.
- **Messages d'assertion axe avec `JSON.stringify(violations, null, 2)`** — debug-friendly en cas de régression future.
- **Personas distincts des specs unit** — pas de duplication, juste les flux narratifs.

### 🟢 Nits non bloquants

- **Recruiter wall-clock = 2 navigations + render.** Sur un runner CI lent, 5s peut flaker. Soit bump à 7-8s, soit ne mesurer que depuis le `goto('/components/experience')`. À regarder si CI commence à flapper.
- **`dev-audit.spec.ts` ne checke que 2 des 4 colonnes** (NAME + TYPE). L'AC dit "table présente" donc c'est conforme, mais `experience-page.spec.ts` checke les 4 — par cohérence on pourrait aligner.
- **Lighthouse `warn`** — flipper à `error` quand les scores auront stabilisé sur 2-3 PRs. Déjà flaggé dans le work doc.
- **Pas de pass axe en thème sombre.** Le bump `--fg-tertiary` ne touche que le light theme ; le dark theme n'est pas testé. Follow-up déjà documenté.
